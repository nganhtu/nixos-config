# nixos-config — Ithilien

NixOS configuration for a laptop running **niri** (tiling Wayland compositor) with **Noctalia** shell, managed entirely via flake + Home Manager.

## Stack

| Layer | Choice |
|---|---|
| OS | NixOS unstable |
| Compositor | [niri](https://github.com/sodiboo/niri-flake) |
| Shell / bar | [Noctalia](https://github.com/noctalia-dev/noctalia-shell) |
| Terminal | Kitty |
| Editor | Helix |
| Launcher | Fuzzel |
| Input method | Fcitx5 + Bamboo (Vietnamese) |
| GTK theme | adw-gtk3 |
| Icons | Papirus |
| Cursor | macOS (apple-cursor) |

## Structure

```
├── flake.nix                  # inputs + nixosConfigurations.Ithilien
├── configuration.nix          # system: bootloader, services, system packages, fonts
├── hardware-configuration.nix # generated by nixos-generate-config, do not edit
├── home.nix                   # Home Manager entry point
├── modules/
│   ├── niri.nix               # full niri settings (input, layout, keybinds, rules, animations)
│   ├── kitty.nix              # terminal + Cherry Midnight theme
│   ├── helix.nix              # editor + transparent_focus_nova theme
│   ├── btop.nix               # system monitor (nord theme)
│   ├── fuzzel.nix             # launcher (noctalia runtime colors via include)
│   ├── theme.nix              # GTK theme, cursor, icon theme, system font
│   └── claude.nix             # Claude Code statusline
├── claude/
│   └── statusline.sh          # statusline script (context %, quota %, git branch)
└── fonts/
    ├── google-sans/           # Google Sans (OFL)
    ├── google-sans-code/      # Google Sans Code (OFL)
    └── windows/               # Windows fonts — personal copy, not redistributed
```

## Applying the configuration

```sh
# Full rebuild (run from repo root)
sudo nixos-rebuild switch --flake .#Ithilien

# Update all inputs then rebuild
nix flake update && sudo nixos-rebuild switch --flake .#Ithilien

# Garbage collect old generations
nix-collect-garbage -d
sudo nix-collect-garbage -d
```

## Key bindings (excerpt)

| Binding | Action |
|---|---|
| `Mod+Return` | Open Kitty |
| `Mod+Space` | Fuzzel launcher |
| `Mod+B` | Google Chrome |
| `Mod+E` | Thunar |
| `Mod+Shift+S` | Area screenshot → clipboard + Swappy |
| `Mod+Shift+F` | Fullscreen screenshot → clipboard |
| `Mod+V` | Clipboard history (cliphist) |
| `Mod+Q` | Close window |
| `Mod+F` | Fullscreen |
| `Mod+Shift+E` | Exit niri |

See `modules/niri.nix` for the full keybind list.

## Fonts note

`fonts/windows/` contains fonts copied from a personal Windows installation. They are not redistributed — if you clone this repo you need to supply your own copies or remove that directory and the `proprietary-fonts` derivation in `configuration.nix`.

`fonts/google-sans/` and `fonts/google-sans-code/` are licensed under the SIL Open Font License (see `OFL.txt` in each directory).

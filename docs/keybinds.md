# Key bindings

All niri bindings, defined declaratively in [`modules/niri.nix`](../modules/niri.nix). `Mod` is the Super key.

## Apps & system
| Binding | Action |
|---|---|
| `Mod+Return` | Open Kitty terminal |
| `Mod+D` | App launcher (Noctalia) |
| `Mod+B` | Google Chrome |
| `Mod+E` | Thunar file manager |
| `Mod+V` | Clipboard panel (Noctalia) |
| `Mod+Alt+V` | Clipboard history picker (cliphist → fuzzel) |
| `Mod+Alt+D` | File search (fd → fuzzel → xdg-open) |
| `Mod+Alt+L` | Lock screen |
| `Mod+Shift+Q` | Session menu (power / logout) |
| `Mod+Shift+Escape` | Show hotkey overlay |
| `Mod+Escape` | Toggle keyboard shortcuts inhibit |
| `Mod+Grave` | Toggle overview |
| `Mod+Shift+P` | Power off monitors |
| `Ctrl+Alt+Delete` | Quit niri |

## Screenshots
| Binding | Action |
|---|---|
| `Mod+Shift+S` | Area screenshot → clipboard + Swappy |
| `Print` | Full screen capture (no pointer) |
| `Mod+Ctrl+Shift+S` | Capture focused window |

## Media & hardware
| Binding | Action |
|---|---|
| `XF86AudioRaiseVolume` | Volume up |
| `XF86AudioLowerVolume` | Volume down |
| `XF86AudioMute` | Toggle mute |
| `XF86AudioMicMute` | Toggle mic mute |
| `XF86AudioPlay` / `Pause` | Play / Pause |
| `XF86AudioNext` | Next track |
| `XF86AudioPrev` | Previous track |
| `XF86MonBrightnessUp` | Brightness up |
| `XF86MonBrightnessDown` | Brightness down |

## Window focus & movement
| Binding | Action |
|---|---|
| `Mod+H/J/K/L` | Focus left / down / up / right |
| `Mod+Arrow` | Focus (arrow equivalent) |
| `Mod+Ctrl+H/J/K/L` | Move column/window left / down / up / right |
| `Mod+Ctrl+Arrow` | Move (arrow equivalent) |
| `Mod+Shift+Arrow` | Focus monitor in direction |
| `Mod+Shift+Ctrl+Arrow` | Move column to monitor in direction |
| `Mod+Home` / `Mod+End` | Focus first / last column |
| `Mod+Ctrl+Home` / `Mod+Ctrl+End` | Move column to first / last |
| `Mod+Q` | Close window |
| `Mod+T` | Toggle window floating |
| `Mod+Ctrl+F` | Toggle fullscreen |
| `Mod+W` | Toggle column tabbed display |

## Workspace
| Binding | Action |
|---|---|
| `Mod+1` … `Mod+0` | Switch to workspace 1–10 |
| `Mod+Shift+1` … `Mod+Shift+0` | Move column to workspace 1–10 |
| `Mod+Tab` | Switch to previous workspace |
| `Mod+Shift+Tab` | Switch to previous window |
| `Mod+Alt+Up/Down` | Focus workspace up / down |
| `Mod+WheelScrollUp/Down` | Focus workspace up / down |
| `Mod+Ctrl+WheelScrollUp/Down` | Move column to workspace up / down |

## Layout
| Binding | Action |
|---|---|
| `Mod+F` | Set column width 100% |
| `Mod+Shift+F` | Expand column to available width |
| `Mod+C` | Center focused column |
| `Mod+Shift+C` | Center all visible columns |
| `Mod+Minus` / `Mod+Equal` | Column width −10% / +10% |
| `Mod+Shift+Minus` / `Mod+Shift+Equal` | Window height −10% / +10% |
| `Mod+WheelScrollLeft/Right` | Focus column left / right |
| `Mod+Shift+WheelScrollLeft/Right` | Focus column left / right (alias) |
| `Mod+Ctrl+WheelScrollLeft/Right` | Move column left / right |
